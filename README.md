# Proiect D4-T1 | Achiziție semnal audio

## Informații Echipă
* **Grupa/Echipa:** 31-E5
* **Studenți:** IANCU MIHAI-ADRIAN, LĂZĂRESCU MOISE-ADRIAN

## Descriere Proiect
Acest script înregistrează un semnal audio de 15 secunde prin microfonul calculatorului și îl identifică dintr-un set de fișiere MP3 locale salvate în folderul `D:/Muzica`. 
Identificarea se face pe baza amprentelor audio extrase prin coeficienții MFCC (medie și deviație standard), comparate ulterior prin distanța cosinusoidală.
